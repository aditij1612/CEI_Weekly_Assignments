# Spark Assignment - Week 5

This repository contains solutions for Week 5 Apache Spark and PySpark DataFrame assignments implemented in Google Colab.

## Dataset
- Dataset Used: Combined E-commerce Dataset (`Combined_dataset.csv`)
- The dataset contains product information such as:
  - product_id
  - title
  - category
  - seller_name
  - final_price
  - ratings and other product attributes

## Topics Covered
- DataFrame creation and schema inference
- Removing duplicate records
- Handling missing values
- Filtering and grouping data
- Aggregations (count, sum, avg, min, max)
- Data cleaning and transformations
- Timestamp conversion
- Spark DataFrame immutability
- Shuffle operations and wide transformations
