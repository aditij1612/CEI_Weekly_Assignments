# Apache Spark Data Processing using PySpark

This repository contains my **Week 6 Apache Spark assignment**, completed using **PySpark in Google Colab**. The assignment focuses on understanding Spark architecture and performing basic data processing operations using Spark DataFrames.

## Objectives

* Understand Spark Architecture (Driver, Cluster Manager, Executors)
* Learn Lazy Evaluation and DAG
* Read data from CSV and Parquet files
* Perform filtering and column selection
* Rename columns, cast data types, and add new columns
* Apply transformations and actions
* Handle null values
* Understand Shuffle and Predicate Pushdown
* Compare CSV and Parquet file formats
* Build a simple data processing pipeline
* Save processed data as CSV and Parquet
* Follow Spark best practices (`show()` instead of `collect()`)

## Technologies Used

* Python
* PySpark
* Apache Spark
* Google Colab

## Dataset

* Sample - Superstore.csv

## Repository Contents

* `Week6_Assignment.ipynb` – Jupyter notebook containing the complete assignment.
* `README.md` – Project documentation.

## Learning Outcomes

Through this assignment, I gained hands-on experience with Spark DataFrames, data transformations, schema handling, file formats, and basic performance optimization techniques used in Apache Spark.
