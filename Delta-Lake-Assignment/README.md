# Delta Lake SCD Assignment

## Objective
Perform incremental data processing using Delta Lake MERGE.

## Steps Performed
- Loaded customer master dataset
- Handled null values
- Removed duplicate records
- Created a Delta table
- Loaded incremental customer dataset
- Applied MERGE operation
- Validated the final output

## Tools Used
- Databricks
- Apache Spark
- Delta Lake
- Python

## Result
The Delta table was successfully updated with existing customer changes and new customer records were inserted.
